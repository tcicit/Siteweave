## What is Siteweave?

**Siteweave** is a user-friendly desktop application for creating and managing static websites. It bridges the simplicity of Markdown writing with the power of a full-featured static site generator — all within an integrated graphical environment, without requiring any command-line knowledge.

*Weave your web.* — Siteweave started as a simple command-line Markdown renderer and has evolved into a comprehensive desktop tool for managing static web projects. It provides everything a content creator or developer needs to write content, organize projects, apply themes, extend functionality via plugins, and publish professional-quality static websites.

## Who is Siteweave For?

- Content creators and bloggers who prefer writing in Markdown
- Developers building static websites without a heavy CMS
- Technical writers creating documentation
- Hobbyists managing personal or family websites
- Anyone who wants full control over their site without proprietary platforms

## Core Philosophy

**Markdown-First:** All content is authored in standard Markdown — a widely supported, human-readable format that remains future-proof.

**Plugin-Powered:** Functionality is extended via Python plugins using a clean double-bracket syntax: `[[plugin_name param="value"]]`.

**Template-Driven:** Page appearance is controlled by Jinja2 templates, enabling complete design freedom.

**Open & Portable:** Projects are plain folders with Markdown files. No lock-in. Licensed under GPLv3.

## Key Capabilities at a Glance

| **Feature** | **Description** |
| :--- | :--- |
| **Markdown Editor** | Syntax highlighting, live preview, line numbers, snippets |
| **Project Management** | Manage multiple website projects side by side |
| **Static Site Generator** | One-click HTML rendering from Markdown + Jinja2 templates |
| **Plugin System** | 18+ built-in plugins; write your own in Python |
| **Project Tools** | Link checker, image compressor, content backup, spellchecker |
| **Quality Assurance** | Markdown linter, Frontmatter validator |
| **Bulk Editing** | Edit metadata for multiple files simultaneously |
| **PDF Export** | Generate documentation PDFs from your content |
| **Themes** | Light and Dark mode; custom CSS themes |
| **Multilingual (i18n)** | Interface language support for multiple locales |
| **Snippets** | Save and reuse common text patterns |
| **Worker Scripts** | Background task automation support |

This is not a plugin, but an example of how to define an iframe in Markdown.

```
<!-- Ein OpenStreetMap Kartenausschnitt als iFrame -->
<iframe
  width="100%"
  height="400"
  frameborder="0"
  scrolling="no"
  marginheight="0"
  marginwidth="0"
  src="https://www.openstreetmap.org/export/embed.html?bbox=8.5417%2C47.3769%2C8.5450%2C47.3785&amp;layer=mapnik">
</iframe>
<p>
  <a href="https://www.openstreetmap.org/#map=19/47.3777/8.5433">View larger map</a>
</p>
```

Encloses the content with a `<span>` tag and applies the specified
text or background color.

## Usage:
```

[color text="red"]]This text is red.[[/color]]
[[color bg="#f0f0f0"]]This text has a light gray background.[[/color]]
[[color text="blue" bg="yellow"]]Blue text on a yellow background.[[/color]]

```

## Example

This is normal text.

This sentence contains [[color text="red"]]red text[[/color]] to emphasize something important.

You can also change the background color to achieve a [[color bg="#fff59d"]]highlighter effect[[/color]].

And of course, [[color text="white" bg="#435B73"]]both properties can be combined[[/color]] to match the design of the page.
